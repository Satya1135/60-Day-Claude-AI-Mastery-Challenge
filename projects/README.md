## Main Capstone Project

### AI-Powered Linux Malware & Privilege-Escalation Investigation Workspace

**Repository**: [github.com/Satya1135/ai-linux-investigation-workspace](https://github.com/Satya1135/ai-linux-investigation-workspace)  
**Release**: [v1.0.0](https://github.com/Satya1135/ai-linux-investigation-workspace/releases/tag/v1.0.0)  
**Classification**: Portfolio / Demo MVP — Local Security Workstation  
**Sprint**: 10 engineering days (Days 1–10 of capstone)  

A full-stack security operations workstation that enables analysts to ingest Linux system logs, reconstruct forensic timelines, run deterministic threat correlation, adjudicate findings, and generate incident reports.

**Key Technologies**: React 18, TypeScript, Vite, FastAPI, Python, Pydantic v2, TanStack Query, CSS Modules  
**Live Frontend**: [https://ai-linux-investigation-frontend.onrender.com/](https://ai-linux-investigation-frontend.onrender.com/)  
**Live Backend API**: [https://ai-linux-investigation-workspace.onrender.com/](https://ai-linux-investigation-workspace.onrender.com/)

For full documentation see [docs/capstone-retrospective.md](../docs/capstone-retrospective.md).
