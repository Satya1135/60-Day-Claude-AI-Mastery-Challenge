## Capstone Sprint — Engineering Log (Days 3–10)

- **[Day 03 Log](daily-logs/Day-03.md)**: FastAPI backend initialization, React/TypeScript shell, health check endpoint, 4 automated unit tests, and CSS variable design system.
- **[Day 04 Log](daily-logs/Day-04.md)**: Evidence upload service, SHA-256 fingerprinting, parsers for `auth.log`, `syslog`, `auditd`, path traversal checks, 31 backend tests.
- **[Day 05 Log](daily-logs/Day-05.md)**: Chronological forensic timeline, attack stage classification, anomaly severity scoring, 3-column cockpit UI, 45 backend tests.
- **[Day 06 Log](daily-logs/Day-06.md)**: 5-stage deterministic threat correlation engine, MITRE ATT&CK mapping, 7 grounded detections, confidence math, 58 backend tests.
- **[Day 07 Log](daily-logs/Day-07.md)**: Analyst adjudication workflow (Confirm, Reject, Edit, Pend), `localStorage` case persistence, standardized `LIN-YYYYMMDD-XXXXX` case IDs.
- **[Day 08 Log](daily-logs/Day-08.md)**: 8-section forensic report viewer, standalone sanitized HTML export (`escapeHtml`), browser-native A4 PDF export (`@media print`), 68 tests.
- **[Day 09 Log](daily-logs/Day-09.md)**: Path traversal defense (`Path.is_relative_to`), Render CORS configuration, dynamic dashboard metrics, mobile drawer navigation, WCAG accessibility, 71 tests.
- **[Day 10 Log](daily-logs/Day-10.md)**: Repository integrity audit, portfolio documentation suite, 30-day and 3/6/12-month roadmaps, v1.0.0 release packaging.
